What it does

Turn any React or React Native codebase into a map your AI can actually reason about.

⌘

Component tree analysis

Full hierarchy, relationships, and structure. Find components by name or type. Detect circular dependencies instantly.

⚡

Complexity scoring

Every component graded 1-10. Spot refactoring candidates before they become tech debt. Density-based audit grades A-F.

↯

Navigation mapping

Auto-detects React Navigation, Next.js App Router, React Router v6/v7, and Remix. See every screen, every route.

◉

Data flow tracing

Prop drilling detection. Context map. Hook dependencies. Trace where state lives and how it moves through your app.

⬡

Interactive visualizer

D3-powered dendrogram in a VS Code webview. Your AI highlights, annotates, and traces flows in real time as it explores.

◎

Runtime inspection

Connect to a running app for live component trees, state, props, and hooks. Modify state from the editor.

How to use it

Two minutes from install to first audit.

Install the extension

One click from the VS Code Marketplace, or run ext install RooneyTech.dendro-react.

Point your AI at it

Add Dendro to your .mcp.json. Works with Claude Code, Cursor, Windsurf, or any MCP client.

Ask for an audit

"Use Dendro to give me an architecture overview of this codebase." Your agent does the rest.
